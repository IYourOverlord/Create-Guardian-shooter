# Create: Guardian-Shooter (`cbc_autotarget`)

**Create: Guardian-Shooter** — это дополнение (аддон) для мода **Create Big Cannons**, добавляющее системы автоматического наведения, автономный ИИ для управления техникой и средства автоматизации артиллерии. Мод полностью интегрирован с экосистемой **Create** и **Create Aeronautics** (через библиотеку **Sable**).

---

## Технический стек проекта
* **Версия Minecraft:** `1.21.1`
* **Загрузчик модов:** `NeoForge` (версия `21.1.227`)
* **Среда сборки:** `Gradle` с плагином `net.neoforged.moddev 2.0.141`
* **Маппинги:** `Parchment 2025.12.20`
* **Основные зависимости:**
  * `create-1.21.1-6.0.10.jar`
  * `createbigcannons-5.11.3-mc.1.21.1.jar`
  * `sable-neoforge-1.21.1-1.2.1.jar`
  * `create-aeronautics-bundled-1.21.1-1.2.1.jar`

## Ключевые возможности и особенности мода

### 1. Автоматический контроллер пушки (Cannon Controller)
Блок, позволяющий пушкам из *Create Big Cannons* автоматически обнаруживать цели, рассчитывать траекторию и вести огонь.
* **Четыре уровня (Tiers 1–4):**
  * **Tier 1:** Радиус сканирования **25 блоков**.
  * **Tier 2:** Радиус сканирования **50 блоков**.
  * **Tier 3:** Радиус сканирования **100 блоков**.
  * **Tier 4:** Радиус сканирования **200 блоков**.
* **Фильтрация целей:** через интерактивный интерфейс (GUI) можно настроить наведение на враждебных мобов, мирных мобов, игроков, вражеские пушки и вражеских командиров.
* **Белый список (Whitelist):** тонкая настройка атаки конкретных игроков по именам.
* **Баллистический решатель (`BallisticSolver`):** использует численный алгоритм (метод Брента) для расчёта баллистической траектории снаряда с учётом его начальной скорости, гравитации, сопротивления воздуха и длины ствола. Симуляция полностью согласуется с физической моделью полёта снарядов из *Create Big Cannons*.
* **Интеграция с Create Aeronautics:** благодаря решателю `ShipAimSolver` и библиотеке `Sable`, автоматические пушки могут точно наводиться и стрелять прямо с летящих кораблей, компенсируя относительное движение и вращение конструкций.

### 2. Командир пушки (Cannon Commander)
Блок управления и идентификации альянсов.
* **Ключ альянса (Alliance Key):** позволяет группировать автоматические пушки игроков. Системы с одинаковым ключом считают друг друга союзниками и не ведут взаимный огонь.
* Защищает пушки игрока от случайного автонаведения со стороны дружественных систем.

### 3. Машинная душа (Machine Soul)
Продвинутый блок автономного ИИ для создания беспилотных аппаратов и турелей.
* **Интерфейс настройки (GUI) разделен на 4 вкладки:**
  * **Vision (Зрение):** регулировка радиуса обзора, дистанции удержания (блок будет отдавать команду отступления, если цель подойдёт слишком близко) и зоны покоя (для избежания лишних микродвижений при отслеживании целей).
  * **Movement (Движение):** настройка частот беспроводных редстоун-линз (Redstone Links) из *Create* для подачи сигналов перемещения во всех шести направлениях (вперёд, назад, влево, вправо, вверх, вниз).
  * **Action (Действие):** назначение частоты для сигнала стрельбы (FIRE). Сигнал подаётся только тогда, когда цель находится в передней полусфере обзора блока (сектор ±90°).
  * **Target (Цель):** переключение ведения огня по игрокам с поддержкой трёх режимов белого списка (Атаковать только указанных / Атаковать всех кроме указанных / Сопровождать указанных).
* **Режим "Physical structure only" (Только на физической конструкции):** позволяет автоматически отключать ИИ и работу Машинной души, если конструкция теряет статус летящего корабля (Sable SubLevel).

### 4. Сборщик гильз (Cartridge Collector)
Блок автоматизации сбора стреляных гильз.
* Автоматически притягивает лежащие на земле пустые гильзы и патронные ящики (`createbigcannons:big_cartridge`, `createbigcannons:empty_autocannon_cartridge`) в радиусе **10 блоков** каждые 5 секунд.
* Вместимость хранилища: **36 стаков** (аналогично инвентарю игрока).
* **Взаимодействие:** правый клик по блоку мгновенно выгружает всё собранное в инвентарь игрока.
* **Автоматизация:** поддерживает интеграцию с трубами/воронками через систему возможностей (Capabilities) в режиме "только извлечение" (read-only).

## Конфигурация мода (`cbc_autotarget-server.toml`)
Вы можете настроить параметры мода под свой сервер:
* `scan_interval_ticks` — интервал сканирования целей (по умолчанию 30 тиков).
* `max_sim_ticks` — максимальное время симуляции баллистики (по умолчанию 400 тиков).
* `muzzle_speed_blocks_per_tick` — базовая скорость снаряда для расчётов (по умолчанию 10.0).
* `default_gravity` — сила гравитации для расчётов траектории (по умолчанию -0.05).
* `default_drag` — коэффициент сопротивления воздуха по умолчанию (0.0).
* `barrel_length` — физическая длина ствола от оси вращения (по умолчанию 0.0 — от центра крепления).
* `max_raycast_candidates` — максимальное число проверяемых по прямой видимости целей за тик для оптимизации производительности (по умолчанию 3).

## Сохранение при чертежах (SafeNbtWriter)
Мод использует реестр безопасной записи NBT от *Create* (`SafeNbtWriterRegistry`). Контроллеры, командиры и машинные души полностью сохраняют свои внутренние настройки, фильтры и белый список при копировании и развёртывании через схематики пушками-схематизаторами (*Schematicannon*).
