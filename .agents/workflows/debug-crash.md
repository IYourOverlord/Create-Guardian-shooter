# debug-crash
Steps:
1. Ask for the full crash log or stack trace if not visible in context.
2. Identify root cause from the first `Caused by:` line — do not read symptoms.
3. State root cause in one sentence.
4. Show the exact fix — changed lines only (±3 lines context).
5. If cause is ambiguous, list max 2 hypotheses with a one-line trade-off each, then ask which to pursue.
